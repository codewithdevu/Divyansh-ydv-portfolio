# Divyansh Yadav - MERN Stack Developer Portfolio

Clean, high-signal, developer-focused portfolio inspired by [ayushworks.com](https://ayushworks.com/).

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS (Dark Mode Priority)
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Deployment**: Vercel / Render

## Quick Start

```bash
# 1. Navigate into project directory
cd D:\mern-portfolio

# 2. Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

## Structure
- `data/portfolioData.ts`: Central data source for all projects, skills, education, and blog posts.
- `components/`: Modular UI components (`Header`, `HeroSection`, `ProjectsSection`, `SkillsSection`, `EducationSection`, `BlogSection`, `ContactSection`, `ResumeModal`, `Footer`).
- `app/`: Next.js 15 layout and styling configuration.
